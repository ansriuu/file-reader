# file-reader


***read_out.c***
This is a small program in c which takes files as input and proceeds to read it outloud to you, that is it output the file's content, at an readable speed.

The program's work is similar to cat command on linux systems.

---


The motivation for the program came from making the lyrics of songs appear slowly when I hear songs , that is also the reason why there's a delay in the output.

This specific program doesn't include syncing with the lyrics according to the timing of sentences, as later I sifted to just making a file reader. I plan on using it another project that I am working on.

Still, it can be used for lyrics and I use it for that too, you may look at it .
